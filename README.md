# LabFetch

LabFetch is a web platform developed as part of the **2CP Multidisciplinary Project at ESI Algiers**. It automates the collection, management, and analysis of scientific publications and researcher supervision activities within the **LMCS Laboratory**.

## 🎯 Objectives

* Centralize the laboratory's scientific publications and research output
* Generate advanced statistics about researchers and projects
* Save time and improve administrative efficiency

## 🛠️ Technologies

* **Frontend:** React
* **Backend:** Express.js
* **Web Scraping:** BeautifulSoup, Selenium

## ✨ Features

* Automated data extraction from **Google Scholar** and **DBLP**
* Multi-user management with role-based access
* Interactive data visualization with charts and dynamic tables
* Centralized management of scientific publications
* Statistical analysis of researchers and projects

## 👥 Project

LabFetch was developed as a **team project in an academic setting in 2025**, combining web development, web scraping, data management, and interactive data visualization.

## Code Availability

The source code is not publicly available because this project was developed collaboratively within an academic context and contains internal configuration details. This repository is intended to present the project, its objectives, and my experience while respecting the team's work and security requirements
